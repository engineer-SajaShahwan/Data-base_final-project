# Data-base_final-project
E-commerce Database Project
Create a database named ecommerce_2.

Main tables:

Categories → Product categories.

Products → Products with prices and discounts.

Customers → Customer information.

Orders → Orders.

Order_items → Details of products within orders.

Data insertion (INSERT) operations for all tables.

Various SQL queries to update prices, delete data, and perform searches.

SQL queries for data aggregation (COUNT, SUM, AVG, MAX, MIN).

Use of JOINs to link tables and display aggregated information.

Use of UNION to combine category and product data in a single query.
